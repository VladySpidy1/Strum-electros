# ElectroS WiFi — облачный протокол (electros.org.ua)

Разобрано по `https://electros.org.ua/auth/protected_page.php` (прошивка/страница «Версія 1.1.4 від 20.09.2025»), 2026-10-28.
Команды на зарядку при разборе не отправлялись — только чтение страницы и входящего статуса.

## Транспорт

1. `GET /auth/main.php`, затем `POST /auth/login.php` с `username=<login>&password=<password>` → сессионные cookie.
2. WebSocket `wss://electros.org.ua/ws/`, subprotocol `example-protocol`, с этими cookie.
3. Каждое сообщение начинается с `site <login>`, строки разделены `\n`.
   Страница шлёт `site <login>` раз в секунду и получает в ответ статус (см. ниже).

Локально (без облака): `ws://<ip зарядки>/ws`, порт 80, без логина и TLS — так делает
[podzolkov#1](https://github.com/podzolkov/electros-ev-ha-from-andriy/pull/1). Косвенно подтверждает
закомментированная строка в странице облака: `ws://${window.location.hostname}/ws` — та же страница
раньше отдавалась самой зарядкой. На нашей зарядке локальный режим ещё не проверен; IP `192.168.1.125`
из настроек с ПК (сеть 192.168.0.x) не отвечает.

## Команды (клиент → облако)

| Команда | Тело после `site <login>\n` | Кнопка на странице |
|---|---|---|
| Статус | (пусто) | опрос раз в секунду |
| Старт | `start\n<idx>\n0\n` — `idx` = индекс тока: 0=32A, 1=30A … 13=6A (шаг 2 А) | «Почати» |
| Стоп | `stop` | «Зупинити» |
| Таймер вкл | `datetime\n<dd.mm.yyyyThh:mm:ss>\n<HH:MM старт>\n<HH:MM стоп>\n` | ⏰ «Задати», тумблер вкл |
| Таймер выкл | `datetime\n<dd.mm.yyyyThh:mm:ss>\n\n\n` | ⏰ «Задати», тумблер выкл |
| Сброс счётчика кВт·ч | `resetkwt` | 📄 «Reset кВт» |
| Настройки | `settings\n…` — Wi-Fi SSID/пароль, IP/порт, заземление, утечка, мин. напряжение, пароль облака | 🛠️ «Задати» |

- `datetime` заодно выставляет часы зарядки (время ПК браузера, если стоит «Час ПК»).
- Окно таймера — ежедневное `HH:MM–HH:MM`. Состояние тумблера страница из статуса не читает;
  при выключенном таймере зарядка отдаёт `00:00`/`00:00` в полях 26/27 (проверено на одном снимке).
- Последний `0` в `start` — назначение неизвестно, страница всегда шлёт `0`.
- `settings` перезаписывает Wi-Fi и пароль облака целиком — из автоматизаций **не слать**.

## Расхождения с интеграцией podzolkov/electros-ev-ha-from-andriy v1.2.0

- Сенсор «Mains voltage» берёт поле 16 (**максимум** за период), а не 10 (текущее) — и мощность считает от него.
- Энергия (11), мощность с устройства (12), таймер (26/27), журнал (30) и история (32) не читаются.
- Команды `datetime` (таймер) и `resetkwt` не реализованы.

Открытые PR (nitogel, 2026-10-26, не смёржены; вместе сливаются без текстовых конфликтов):
- #1 локальный режим, #2 статусы 32/77, #3 энергия (11), мощность (12), кнопка `resetkwt`.
- После всех трёх остаётся: напряжение всё ещё из поля 16; `reset_energy` из #3 всегда логинится в облако,
  поэтому в локальном режиме без интернета не сработает; в локальном режиме пароль облака всё равно обязателен.
